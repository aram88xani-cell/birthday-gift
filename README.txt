# صفحة عيد ميلاد 🎂

1. افتحي ملف `index.html` في المتصفح.
2. اضغطي "اختاري صورتنا من جهازك" واختاري صورتك أنتِ ورفيقتك.
3. إذا تريدين صورة ثابتة بدل الصورة الافتراضية، استبدلي `photo-placeholder.jpg` بصورة باسم الملف نفسه.
4. الملف `reference-video.mp4` هو الفيديو المرفوع، ويمكنك الاحتفاظ به أو حذفه؛ الصفحة لا تحتاجه للتشغيل.

الصفحة تعمل بدون خادم، فقط افتحي `index.html`.
